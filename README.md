#  MediMap

MediMap is an interactive hospital navigation platform designed to help patients, visitors, and healthcare professionals easily explore hospital buildings.

## Vision

Our goal is to provide a modern, intuitive, and accessible digital map for hospitals, making navigation simple and improving the overall hospital experience.

## Main Features

-  Interactive hospital map
-  Multiple buildings
-  Floor navigation
-  Room details
-  Doctor directory
-  Department directory
-  Global search
-  Multi-language support
-  Dark mode
-  Accessibility settings

## Repositories

- **medimap-frontend** — React + TypeScript application
- **medimap-backend** — Spring Boot REST API

## Tech Stack

- React
- TypeScript
- Java 21
- Spring Boot
- PostgreSQL
- Docker
